# UPRM Edge - Subproject 1

Repositorio de trabajo para el Subproyecto 1 de UPRM Edge.

## Contenido actual

- `Valid Core Programs-20261016/`: programas de referencia que cumplen con las reglas del lenguaje.
- `Invalid Core Programs-20261016/`: casos de prueba con errores intencionales.
- `Memory Track-20261016/`: programas para validar el presupuesto de memoria.
- `UPRM-Edge-Subproject1-Instructions.pdf`: instrucciones oficiales del subproyecto.
- `UPRM-Edge-Track-Selection-Guide.pdf`: guía para seleccionar el track.

## Forma de trabajo

1. Cree una rama para cada cambio: `feature/nombre-corto` o `fix/nombre-corto`.
2. Mantenga cada cambio enfocado y descríbalo en un pull request.
3. Antes de solicitar revisión, pruebe los programas afectados y anote el resultado en el pull request.
4. No suba archivos temporales, binarios generados ni credenciales.
